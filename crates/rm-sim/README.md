# rm-sim

Development placeholder for the actively developed
[RoboMaster simulator](https://github.com/trident-rm/rm-simulator).

The repository contains the working simulator, competition gameplay, robot and
arena models, physics, sensors, multiplayer application and renderer. Work is
underway to separate a lightweight reusable simulation engine from RoboMaster
specific behavior, with explicit stepping and modular component interfaces.

Version **0.0.0-dev** establishes the project's public package name. It does not
ship the simulator or expose a Rust simulation API yet. For installation,
examples, documentation and ongoing development, use the repository above.

Licensed under MIT OR Apache-2.0. This package includes no competition CAD,
third-party robot models or other simulator assets.
